What it does

Six reasons this workflow is different

  • 01

    Runs on a schedule. You wake up to a report.

    A hive scheduler dispatches the agent at 9 AM daily. By the time you open your laptop, the check has run, the Google Sheet is updated, and a performance report is sitting in the agent's output folder.

  • 02

    Tokens stored in macOS Keychain — nothing on disk.

    Meta access tokens are stored as Keychain entries (meta-<tag>) using the security CLI. The agent reads them at runtime. They never touch a .env file, a config file, or git.

  • 03

    Writes back to your Google Sheet automatically.

    A GCP service account handles Sheets read/write. Every daily run updates Column Y with a one-line status — the sheet is both the brief and the live log. Human-readable and agent-readable.

  • 04

    4 clients checked in parallel. Full check in under 10 seconds.

    The system uses Promise.all() to fetch all active campaigns simultaneously against Meta's Graph API. Checking 4 accounts takes ~2 seconds, not 8. No sequential bottleneck.

  • 05

    Zero MCP dependency at runtime. Can't be broken by an upstream timeout.

    The daily check loop runs entirely on fetch() and security — both always available on macOS. No MCP server means no session binding, no tool disappearance mid-run, no upstream failures breaking your audit.

  • 06

    Role separation: one agent reads, one agent executes.

    The Meta Lead agent holds read-only credentials (ads_read, read_insights). It reviews and QA-checks, but never touches a campaign. A separate Meta Executive agent handles writes — and only after a brief from the Lead. No accidental campaign changes.

Who it's for

Built for people who audit Meta at scale

If you're manually checking Meta every morning — opening Ads Manager, scanning spend, cross-referencing your sheet — this replaces that with a scheduled agent that does it for you and reports exceptions. It's designed for agencies managing multiple ad accounts, performance marketers who want an always-on audit layer, and AI builders who want a reference implementation of a production hive agent.
